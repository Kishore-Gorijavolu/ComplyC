# ComplyC Roadmap

## Vision

Build an open-source static analysis and coding-guideline compliance
tool focused on Embedded C and Safety-Critical Software.

# Version 0.3 -- Core Engine Reliability

-   Source Mapping Engine
-   Correct source file/line reporting
-   Header filtering
-   GCC preprocessing improvements
-   Report accuracy

# Version 0.4 -- Static Analysis

-   Symbol Table
-   Improved Dataflow
-   Call Graph
-   Cross Reference
-   CFG improvements

# Version 0.5 -- Coding Standards

-   MISRA-C support
-   AUTOSAR C Guidelines
-   Custom rule packs
-   Rule suppression

# Version 0.6 -- User Experience

-   Open source at violation
-   Progress bar
-   Project settings
-   Scan profiles

# Version 1.0

Production-ready compliance analyzer.
